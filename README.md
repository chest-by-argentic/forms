# Formulaires — créez vos formulaires et retrouvez les réponses.

Outil du catalogue Chest by Argentic. Un Chest le construit lui-même depuis ce dépôt, à un commit épinglé : `chest.json` nomme l’outil, ses permissions et son point d’entrée ; `npm ci` puis `npm run build` produisent `dist/apps/forms/src/worker.js`.

Pour l’adapter : forkez ce dépôt, modifiez-le avec votre agent, liez votre fork à votre Chest.
